# mattdweigand-sketch.github.io

Source for [mattdweigand-sketch.github.io](https://mattdweigand-sketch.github.io/), Matt Weigand's personal site.

Plain HTML, CSS, and a small amount of JavaScript. No build step, no framework, no analytics. Fonts load from Fontshare.

## Files

- `index.html` page content
- `base.css` reset and tokens
- `style.css` layout and components
- `app.js` theme toggle, mobile nav, scroll reveal, active nav
- `assets/` photo and social preview image

## Run locally

Open `index.html` in a browser, or serve the folder with `python3 -m http.server`.
